# تقرير المرحلة الأولى — CITY LIFE (Godot)

## لماذا Godot؟
لا يوجد كمبيوتر لتفعيل رخصة Unity. Godot لا يحتاج رخصة ويُبنى كاملاً من الهاتف عبر GitHub Actions. نسخة Unity بقيت محفوظة (`CityLife_Phase1.zip`) دون مساس.

## الحالة الفعلية (بصراحة)
- **كُتب:** مشروع Godot 4.3 كامل للمرحلة 1 (8 سكربتات، مشهدان، إعدادات تصدير، سير عمل بناء).
- **فُحص ساكناً فقط:** توازن الأقواس، المسافات البادئة، صحة YAML، ومراجعة يدوية للمنطق.
- **لم يُشغَّل في Godot:** بيئتي لا تصل إلى تنزيله. لذلك لا أدّعي أن أي ميزة تعمل. احتمال وجود خطأ أو أكثر في أول تشغيل **مرتفع** (كود GDScript لم يمرّ على مفسّر).
- **الدليل الحقيقي القادم:** 30 فحصاً آلياً في `tests/test_runner.gd` تعمل تلقائياً في البناء السحابي، ونتيجتها في Summary.

## المنفَّذ
| المطلوب | التنفيذ |
|---|---|
| مدينة تجريبية | شبكة طرق 6×6 و25 كتلة، أبراج حتى 110م، أحياء، شقق، محلات، صناعي، حديقة ونافورة، إنارة، أشجار |
| مبانٍ قابلة للدخول | محل ومقهى بأبواب وأرضية وسقف وعداد ورفوف وإضاءة |
| شخصية | ذكر/أنثى Low-Poly بالكود |
| حركة | مشي، جري، قفز، جاذبية، صعود حافة الرصيف |
| أنيميشن | إجرائي (أرجل وأذرع وميل وتنفس) |
| كاميرا | أول/ثالث بانتقال سلس، سحب للتدوير، منع اختراق الجدران |
| لمس | عصا، JUMP, RUN, USE, CAM, GFX، لمس متعدد |
| خريطة صغيرة | كاميرا علوية تدور مع النظر |
| أداء | دمج المجسمات (Mesh واحد لكل خامة لكل كتلة)، حجب بالمسافة، 3 مستويات رسومات، رندرر Compatibility للهواتف الضعيفة |

## قيود معروفة
- **الأنيميشن إجرائي** والمجسمات بسيطة؛ الواقعية تتطلب أصولاً فنية لاحقاً.
- **العربية في الواجهة:** نصوص المرحلة 1 إنجليزية قصيرة. دعم العربية (تشكيل الحروف واتجاه RTL) يحتاج خطاً عربياً وإعداداً خاصاً في مرحلة القوائم؛ Godot 4 يدعمه لكن لم أضفه الآن كي لا أضع شيئاً غير مختبر.
- **وقت التحميل:** المدينة تُبنى بالكود عند التشغيل؛ قد تظهر شاشة «Loading» بضع ثوانٍ على هاتف ضعيف.
- **الجدران ثنائية الوجه** (Cull Disabled) كاحتياط حتى أتأكد من الرسم الصحيح؛ سأحوّلها لاحقاً لتحسين الأداء.
- **التوقيع:** APK بتوقيع debug للتجربة فقط.
- **لم يُنفَّذ عمداً:** القائمة الرئيسية، الهاتف، الحقيبة، الرصيد، السيارات، الاقتصاد، الأونلاين. لا أزرار لها كي لا توجد أزرار ميتة.

## شرط الانتقال إلى المرحلة 2
1. نجاح الـ Workflow وإنتاج `CityLife.apk`.
2. اجتياز الفحوص الآلية (أو إصلاح ما يفشل).
3. تأكيدك على الهاتف: الشخصية تتحرك، CAM يبدّل، الباب يُفتح، والمدينة تظهر بشكل معقول.

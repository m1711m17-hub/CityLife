# CITY LIFE (نسخة Godot) — المرحلة الأولى

لعبة محاكاة حياة ثلاثية الأبعاد لأندرويد. هذه النسخة بمحرك **Godot 4.3** (مجاني تماماً، بدون رخصة، وتُبنى سحابياً بدون كمبيوتر).

> **حالة صريحة:** الكود كُتب وفُحص ساكناً (أقواس، مسافات، YAML) لكنه **لم يُشغَّل في Godot بعد**، لأن بيئتي لا تستطيع تنزيله. أول تشغيل حقيقي سيكون في البناء السحابي. إن ظهر خطأ أرسل لي ملف `test_log.txt` وأصلحه.

## ما الموجود في المرحلة 1
مدينة تجريبية (25 كتلة: وسط، سكن، شقق، محلات، صناعي، حديقة بنافورة) • شخصية ذكر/أنثى (تُغيَّر من `female` في `scripts/main.gd`) • مشي/جري/قفز • كاميرا أول/ثالث شخص بزر **CAM** • عصا لمس + سحب لتدوير الكاميرا • أبواب تُفتح بزر **USE** (المحل والمقهى قابلان للدخول) • خريطة صغيرة • ثلاثة مستويات رسومات بزر **GFX** • اختبارات آلية.

## البناء من الهاتف فقط (بدون كمبيوتر)
1. أنشئ حساباً في github.com (من المتصفح) ثم **New repository** (اجعله Private).
2. **Add file → Upload files**: ارفع ملف `CityLifeGodot_Phase1.zip` كما هو (ملف واحد، لا تفكّه).
3. **Add file → Create new file**: اكتب الاسم `.github/workflows/build-android.yml` (الشرطات المائلة تُنشئ المجلدات)، والصق محتوى الملف `build-android.yml` المرفق معك، ثم **Commit**.
4. افتح تبويب **Actions** ← **Build Android APK (Godot)** ← **Run workflow**. المدة المتوقعة 8–15 دقيقة.
5. بعد النجاح (علامة خضراء) افتح التشغيل ← **Artifacts** ← نزّل `CityLife-apk-and-logs` ← فكّ الضغط (من تطبيق الملفات) ← ثبّت `CityLife.apk` (فعّل «تثبيت من مصادر غير معروفة»).
6. في صفحة التشغيل نفسها قسم **Summary** فيه نتيجة الاختبارات (PASS/FAIL). حتى لو فشل اختبار يُبنى الـ APK.

إن فشل أي شيء: انسخ لي نص الخطأ من Actions أو أرسل `test_log.txt` / `export_log.txt` من الـ Artifacts.

## التحكم
- العصا (يسار): حركة. اسحب الجانب الأيمن: الكاميرا.
- JUMP قفز • RUN جري دائم/إيقاف • USE تفاعل (يضيء قرب الأبواب) • CAM أول/ثالث • GFX مستوى الرسومات.
- لوحة المفاتيح (للاختبار): WASD، Shift، Space، E، V، وزر الماوس الأيمن للتدوير.

## الهيكل
```
scripts/  main, city_builder, player, camera_rig, touch_ui, door, controls
scenes/   main.tscn          tests/  test_runner (اختبارات آلية)
assets/   مجلدات جاهزة للمراحل القادمة (Vehicles, Networking, SaveSystem ...)
.github/workflows/build-android.yml   البناء السحابي
```
كل شيء (المدينة، الشخصية، النوافذ، الواجهة) يُولَّد بالكود؛ لا توجد ملفات فنية خارجية.

## تشغيل الاختبارات يدوياً (إن توفر كمبيوتر مستقبلاً)
`godot --headless res://tests/test_runner.tscn`
